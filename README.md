# Thomas Han — Portfolio

Editorial portfolio site for Thomas Han, built with Vite + React.

## Local development

```bash
npm install
npm run dev
```

Open the printed `http://localhost:5173` URL.

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` auto-deploy on Vercel. Framework preset: **Vite**. Build: `npm run build`. Output: `dist`.
